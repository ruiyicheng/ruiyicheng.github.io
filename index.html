Current research

Two active directions I am pushing right now

2025 - Present

Agentic Light-Curve Diagnosis with LLM Tool Use

LLM agents coordinating scientific tools for astronomical diagnosis

Building an agentic diagnosis system where an LLM orchestrates period search, catalog queries, Gaia / VSX metadata retrieval, multi-band light-curve inspection, and uncertainty-aware reasoning.

  • Public v1 prototype built with LangChain and DeepAgents.
  • Developing a more stable v2 with stronger state tracking and modular pipelines.
  • Exploring how tool use can combine with classical time-series analysis for reliability and interpretability.
LLM agents Tool use Scientific diagnosis
2025 - Present

Self-Supervised Representation Learning for Irregular Light Curves

Multi-view learning for unevenly sampled astronomical time series

Developing a self-supervised framework that uses raw light curves, folded light curves, periodograms, and visualization-based representations as complementary views.

  • Designed continuous-time positional encoding and uncertainty-aware numerical embeddings.
  • Evaluating learned representations on variable-star classification, few-shot learning, similarity search, OOD detection, and physical-parameter inference.
  • Aiming at generalizable representations that transfer beyond astronomy.
SSL Irregular sampling OOD detection

Selected projects

Projects that connect modeling, data, and infrastructure

Jun. 2023 - Present

Tianyu Large-Scale Time-Series Pipeline

Observation control, data processing, scheduling, and scientific ML

Core developer for Tianyu, a 1-m optical time-domain survey telescope in Lenghu, Qinghai.

  • Built a scalable distributed pipeline for survey-scale light-curve extraction with MySQL + RabbitMQ.
  • Real data reach the theoretical noise limit and support minute-cadence observations.
  • Implementing GPU-accelerated variability analysis and a hierarchical MILP scheduler with LLM-based target selection.
Distributed DAG GPU analysis MILP scheduling
2024 - 2025

DeepAP: Deep Learning for Aperture Photometry

Feasibility classification and aperture-size prediction

Proposed a two-stage deep-learning framework using a ViT for feasibility classification and a ResNet for aperture-size selection.

  • Achieved about 59,000x speed-up over classical methods.
  • Framed aperture selection as a supervised learning problem on real observational data.
ViT ResNet Photometry
2024 - 2026

LenghuSky-8: Multimodal Dataset, Segmentation, and Nowcasting

8-year all-sky cloud dataset with calibration and masks

Developed an 8-year, 429k-image all-sky camera dataset from Lenghu, Qinghai, accepted by CVPR 2026 Findings.

  • Performed absolute astrometric calibration and constructed star-aware cloud masks.
  • Benchmarked cloud segmentation and weather nowcasting models, including DINOv3 linear probing and ConvLSTM.
CVPR 2026 Findings Segmentation Nowcasting
Dec. 2021 - Jun. 2023

Mitigating Astrometric Bias in Barycentric Correction

High-precision radial-velocity time-series correction

Developed a gradient-based method to correct biases in stellar astrometric parameters for precise barycentric correction in Earth-twin exoplanet searches.

  • Showed that astrometric systematics matter at ultra-precise radial-velocity scales.
  • Connected gradient-based correction with time-series analysis for exoplanet work.
Astrometry RV time series Exoplanets
